# VNBabel

Automatically translate Ren'Py visual novel games into 26+ languages.

## Features

- **15 translation engines** — Google, DeepL, Azure, OpenAI, Claude, Gemini, Groq, Mistral, Cohere, OpenRouter, MyMemory, LibreTranslate, Lingva, Apertium, Argos (offline)
- **Drag & drop** — pick the game `.exe`, choose language and engine, done
- **Non-destructive** — all translations written to `tl/` folder only; original files never modified
- **Revertable** — undo any translation instantly
- **Font support** — auto-downloads Noto fonts for Japanese, Chinese, Korean, Arabic, Thai scripts
- **Cache** — resumes interrupted translations without re-translating
